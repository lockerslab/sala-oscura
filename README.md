# La Sala Oscura

Whitepaper interactivo de [Lockers Lab](https://lockerslab.io).

Está en vivo en https://sala-oscura-lockerslab.netlify.app/

## Archivos

- `index.html`: el sitio, en un solo archivo
- `og.png`: imagen para la preview en redes
- `og-preview.png`: otra imagen de preview
- `_headers`: headers de Netlify

## Deploy

Sitio estático, sin paso de build. En Netlify el directorio de publicación es la raíz del repo. `netlify.toml` ya lo configura así. Los headers quedan en `_headers`.
